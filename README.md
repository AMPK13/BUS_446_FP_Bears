# BUS_446_FP_Bears
Final Project for BUS 446 analyzing RPP in the United States
Using data from the Bureau of Economic Analysis for 2022–2023, the project explored the variation in RPP scores and their relationship with median household income. Key objectives included identifying affordability gaps in states where high living costs are not matched by proportionally higher incomes, assessing how housing costs influence RPP, and visualizing patterns through statistical analysis and charts. The findings were used to provide actionable insights for policymakers and individuals considering relocation or investment decisions. This project demonstrates the application of data-driven techniques to real-world economic issues and highlights the importance of geographic pricing data in socioeconomic planning.
